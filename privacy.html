Privacy policy

Last updated: 27 September 2026

Who we are

"Immich to Gphoto Transfer" is a personal, self-hosted application run by a single individual on his own home server for his own Google account. It is not offered to the public.

Data we access

With your consent the application uses the Google OAuth scope https://www.googleapis.com/auth/drive.file and your email address. It calls the Google Drive API about.get endpoint only to read the account's storage quota (total limit and current usage) and the account email address, so that it can show them to the owner and warn when storage grows.

The application does not read, list, download, modify or delete any of your photos, videos or Google Drive files, and does not create files in Drive.

How data is stored

The OAuth refresh token, the storage figures and the account email are stored only on the owner's home server, in a file readable only by the application. Nothing is stored on any other server.

Sharing

No data obtained from Google APIs is sold, shared with, or transferred to any third party, and it is not used for advertising or any purpose other than the storage warning described above.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

You can revoke access at any time at myaccount.google.com/permissions or with the "Disconnect" button in the application, which also deletes the stored token and figures.
